# Share-Meal interface

Existing product: donors publish surplus food; NGOs find nearby listings, request a pickup, and track collection. Preserve the established logo, orange donor identity, green NGO identity, and tab destinations.

Operate mode. ENERGY 1 / RHYTHM 2 / MOTION 1.

- Warm off-white surfaces and dark ink make food details readable outdoors. Burnt orange marks publishing actions; forest green marks collection actions. Semantic colors communicate request and pickup states alongside text.
- System typography supports native accessibility and language coverage. Compact 14–16 point body text and 20–24 point headings prioritize food, quantity, expiry, and the next action.
- Aligned rows and section spacing organize forms and details. Borders separate records; shadows are reserved for controls floating above maps.
- Existing food imagery has fixed dimensions. The existing logo and food/location icons provide identity; no fabricated impact metrics, photography, or audience claims.
- Loading reserves content space. Failed loads show retry; empty results explain the available action. Native touch targets remain at least 48 points.
- Motion is limited to native navigation and press feedback that honors reduced motion. Repeated entrance animation is unnecessary for operational lists.
- Fixed light appearance follows the existing app configuration and supports daytime food collection. This refinement preserves that shipped appearance.
